# Calculator App

A simple calculator application built with Python and Kivy framework.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Percentage calculation
- Sign toggle (±)
- Backspace functionality
- Clear all (C)
- Responsive design
- Color-coded buttons for better user experience

## Build with Buildozer

This app is built for Android using Buildozer. The build process is automated using GitHub Actions.
